# Magpie — browser/search

**Role:** Privacy web access: search via DuckDuckGo (no trackers), no accounts. Goal: a real CLI browser feel (read pages, summarize with local Pixie).

**Status:** search stable; browsing in progress

## Current
- `magpie "query"` / `duck` (alias) — DDG search, link scraping, local summaries (Pixie, offline)
- Integrated with ether (net diagnosis for IPv4 HTTPS)

## Next
- [ ] Article mode: clean text reading (stripped, paginated) in a TUI
- [ ] Read-later queue (local)
- [ ] Save pages as text for offline reading
- [ ] Scroll section refresh with new commands

## Anti-goals
- Trackers, ads, JS-heavy browsing, browser profiles/accounts.
